# SLAM数学直观笔记

本书从集合、拓扑、微分几何与李群建立状态空间和局部扰动的语言，再从测度论走向概率建模，完整推导 ESKF 与 IMU 预积分。

## 当前章节

| 章 | 标题 | 内容 |
|---|---|---|
| 0 | 公理化集合论 | 逻辑、公理、数系与数学对象的构造 |
| 1 | 集合、映射、等价关系与商集 | 状态集合、映射、商构造与良定义性 |
| 2 | 点集拓扑 | 连续性、紧致性、分离性与连通性 |
| 3 | 拓扑流形 | 局部欧氏性、图册、纤维丛预告与商空间 |
| 4 | 微分几何 | 可微结构、切空间、推拉回、度量与优化 |
| 5 | 李群与李代数 | SO(3)、SE(3)、指数映射、伴随与扰动 |
| 6 | 测度论基础：从集合、可测映射到概率 | 集合系与 σ 代数、可测函数、测度与外测度、积分、随机变量及少量 SLAM 对照 |
| 7 | 从局部误差到状态估计：ESKF与IMU预积分 | 沿三维状态连贯理解 IMU 预测、ESKF 更新重置、区间相对运动、偏置修正与优化约束 |
| 8 | ESKF与IMU预积分的完整推导 | 分组展开误差矩阵、噪声离散化、观测与重置、联合协方差、偏置及端点 Jacobian、白化与优化 |

第六章以测度论为主体。第七章沿手写笔记的顺序，把前面的流形、局部误差和概率语言接到完整的 ESKF 与 IMU 预积分流程：保留三维状态，解释每个符号的对象与用途，先不展开大块矩阵。第八章再对照第七章的公式，分别推导两套方法的矩阵和 Jacobian。

两章统一采用机体系到世界系的旋转和右侧姿态误差。完整状态按 `(R, p, v, b_g, b_a)` 排列，预积分运动残差按 `(R, v, p)` 排列；矩阵分别标明行列顺序。预积分沿用 `T_ij`、带波浪线的计算量和上标 `c` 的偏置修正量；状态协方差记为 `P`，九维预积分协方差记为 `Σ`，包含偏置随机游走的联合协方差记为 `Σ^(15)`。

建议先连续读完第七章，建立“输入、计算、保存量、用途”的整体认识，再到第八章追踪各矩阵项的来源。第七章的两步采样例子贯穿预积分计算、偏置修正和端点比较；第八章保留完整推导及离散化、概率模型的适用条件。

## 目录

- `main.tex`：书籍入口、封面与章节顺序。
- `chapters/`：正文和前言。
- `style/newcommand.tex`：本书符号与数学命令。
- `assets/images/`：正文引用的封面与插图。
- `assets/ai-images/`：尚未正式采用的AI生成素材。
- `build/`：编译产物。

## 编译

从工作空间根目录运行：

```bash
make slam-geometry
```

或在本目录运行：

```bash
latexmk -pdfxe -outdir=build main.tex
```

输出为 `build/main.pdf`。
