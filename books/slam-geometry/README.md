# SLAM数学直观笔记

本书从集合、拓扑、微分几何与李群建立状态空间和局部扰动的语言，再从测度论走向概率建模，完整推导 ESKF 与 IMU 预积分。

## 当前章节

| 章 | 标题 | 内容 |
|---|---|---|
| 0 | 公理化集合论 | 逻辑、公理、数系与数学对象的构造 |
| 1 | 集合、映射、等价关系与商集 | 状态集合、映射、商构造与良定义性 |
| 2 | 点集拓扑 | 连续性、紧致性、分离性与连通性 |
| 3 | 拓扑流形 | 局部欧氏性、图册、纤维丛预告与商空间 |
| 4 | 微分几何 | 可微结构、切空间、推拉回、度量与优化 |
| 5 | 李群与李代数 | SO(3)、SE(3)、指数映射、伴随与扰动 |
| 6 | 测度论基础：从集合、可测映射到概率 | 集合系与 σ 代数、可测函数、测度与外测度、积分、随机变量及少量 SLAM 对照 |
| 7 | 误差状态卡尔曼滤波：从局部概率模型到 ESKF | IMU 模型、误差动力学、噪声离散化、观测更新、注入重置与路标案例 |
| 8 | IMU预积分：从起点局部坐标到关键帧因子 | 相对运动、离散递推、联合协方差、偏置修正、因子残差与后端优化 |

第六章以测度论为主体，第七章将局部概率模型落实为递推滤波，第八章将区间运动及其不确定性组织成关键帧因子。后两章统一采用机体系到世界系的旋转和右侧姿态误差；完整状态按 `(R, p, v, b_g, b_a)` 排列，预积分运动残差按 `(R, v, p)` 排列，正文分别标明矩阵的行列顺序。

## 目录

- `main.tex`：书籍入口、封面与章节顺序。
- `chapters/`：正文和前言。
- `style/newcommand.tex`：本书符号与数学命令。
- `assets/images/`：正文引用的封面与插图。
- `assets/ai-images/`：尚未正式采用的AI生成素材。
- `build/`：编译产物。

## 编译

从工作空间根目录运行：

```bash
make slam-geometry
```

或在本目录运行：

```bash
latexmk -pdfxe -outdir=build main.tex
```

输出为 `build/main.pdf`。
