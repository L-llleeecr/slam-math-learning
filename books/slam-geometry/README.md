# SLAM数学直观笔记

本书从集合、拓扑、微分几何与李群建立状态空间和局部扰动的语言，再从测度论走向概率建模，依次讨论 ESKF、IMU 预积分、GICP，以及前端、后端和回环组成的 SLAM 系统。

## 当前章节

| 章 | 标题 | 内容 |
|---|---|---|
| 1 | 公理化集合论 | 逻辑、公理、数系与数学对象的构造 |
| 2 | 集合、映射、等价关系与商集 | 状态集合、映射、商构造与良定义性 |
| 3 | 点集拓扑 | 连续性、紧致性、分离性与连通性 |
| 4 | 拓扑流形 | 局部欧氏性、图册、纤维丛预告与商空间 |
| 5 | 微分几何 | 可微结构、切空间、推拉回、度量与优化 |
| 6 | 李群与李代数 | SO(3)、SE(3)、指数映射、伴随与扰动 |
| 7 | 测度论基础 | 集合系、可测函数、测度与积分，及概率建模 |
| 8 | ESKF直观 | 名义状态、误差传播、观测更新与重置 |
| 9 | ESKF完整推导 | 连续与离散误差、协方差、观测与重置 Jacobian |
| 10 | IMU预积分 | 相对运动、偏置修正、协方差与端点残差 |
| 11 | GICP | 点云对应、局部协方差与位姿优化 |
| 12 | SLAM系统 | 前端、后端、回环与全局校正 |

第 1—7 章建立数学基础。第 8、9 章从直观到推导讲解 ESKF；第 10、11 章分别建立 IMU 与点云的相对约束；第 12 章把这些结果接入完整系统。惯性章节统一采用机体系到世界系的旋转与右侧姿态误差；GICP 的配准推导会单独声明左侧扰动，并在系统接口中保持坐标约定一致。

## 目录

- `main.tex`：书籍入口、封面与章节顺序。
- `chapters/`：正文和前言。
- `style/newcommand.tex`：本书符号与数学命令。
- `assets/images/`：正文引用的封面与插图。
- `assets/ai-images/`：尚未正式采用的AI生成素材。
- `build/main.pdf`：可直接阅读的完整 PDF；其余编译中间文件不发布。

## 编译

从工作空间根目录运行：

```bash
make slam-geometry
```

或在本目录运行：

```bash
latexmk -pdfxe -outdir=build main.tex
```

输出为 `build/main.pdf`。
