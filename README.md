# SLAM数学直观笔记

本书从基础数学语言出发，以拓扑、微分几何和李群为主线，解释SLAM中的状态空间、局部扰动、连续动力学和惯性约束。

## 当前章节

| 章 | 标题 | 内容 |
|---|---|---|
| 0 | 公理化集合论 | 逻辑、公理、数系与数学对象的构造 |
| 1 | 集合、映射、等价关系与商集 | 状态集合、映射、商构造与良定义性 |
| 2 | 点集拓扑 | 连续性、紧致性、分离性与连通性 |
| 3 | 拓扑流形 | 局部欧氏性、图册、纤维丛预告与商空间 |
| 4 | 微分几何 | 可微结构、切空间、推拉回、度量与优化 |
| 5 | 李群与李代数 | SO(3)、SE(3)、指数映射、伴随与扰动 |
| 6 | IMU预积分 | 连续动力学、相对测量、bias Jacobian、协方差和IMU因子 |

## 目录

- `main.tex`：书籍入口、封面与章节顺序。
- `chapters/`：正文和前言。
- `style/newcommand.tex`：本书符号与数学命令。
- `assets/images/`：正文引用的封面与插图。
- `assets/ai-images/`：尚未正式采用的AI生成素材。
- `references/`：参考文献和外部材料。
- `build/`：编译产物。

## 编译

从工作空间根目录运行：

```bash
make slam-geometry
```

或在本目录运行：

```bash
latexmk -pdfxe -outdir=build main.tex
```

输出为 `build/main.pdf`。
